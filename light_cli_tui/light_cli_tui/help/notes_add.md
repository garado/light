Create a new text note.

Provide content inline as an argument, or from a file with `--file`. Prompts for
confirmation before creating; skip with `--yes` or preview with `--dry-run`.

**Examples:**

`light notes add "Shopping list" "eggs, milk, bread"`

`light notes add "Meeting notes" --file notes.txt`

`light notes add "Shopping list" "eggs, milk, bread" --yes`
